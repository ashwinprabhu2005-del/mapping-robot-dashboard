# 🤖 Autonomous 3D Mapping Robot Dashboard

![Dashboard Preview](https://img.shields.io/badge/Status-Active-brightgreen) ![ROS2](https://img.shields.io/badge/ROS2-Humble-blue) ![React](https://img.shields.io/badge/Frontend-React_Vite-cyan) ![Jetson](https://img.shields.io/badge/Hardware-Jetson_Orin_Nano-green)

A complete end-to-end software stack for real-time 3D mapping and spatial awareness using a Jetson Orin Nano and an Intel RealSense Depth Camera. This project features a React-based web dashboard that visualizes live point clouds, tracks robot telemetry, and allows for both manual and AI-driven map annotations.

---

## ✨ Key Features

- **Live 3D Point Cloud Streaming:** View real-time SLAM data generated by `RTAB-Map` directly in your browser.
- **AI-Driven Automatic Annotation:** An onboard YOLO AI model actively scans the camera feed to detect objects (people, chairs, etc.) and automatically drops labeled 3D pins on the map without human intervention.
- **Manual Spatial Annotations:** Click anywhere on the 3D map to drop custom pins (e.g., "Charging Station", "Hazard Zone") that sync to a PostgreSQL database.
- **Remote Lifecycle Management:** Log into the dashboard and remotely power up or shut down the ROS2 camera stack on the Jetson to save battery.
- **Time-Series Telemetry:** Tracks historical robot metrics (speed, CPU usage, etc.) using InfluxDB and MQTT.

---

## 🏗️ Architecture

1. **Hardware (The Edge):** A Jetson Orin Nano running ROS2 Humble and a Node.js Express lifecycle server. It connects to an Intel RealSense D435i camera.
2. **Transportation Layer:** Data is streamed over Wi-Fi using an MQTT Broker (telemetry) and a Rosbridge WebSocket (point clouds).
3. **Databases (Docker Host):**
   - **PostgreSQL:** Stores map metadata, user accounts, and annotation coordinates.
   - **InfluxDB:** Stores high-frequency time-series telemetry.
4. **Frontend:** A React + Vite dashboard displaying the aggregated data.

## 🛠️ Prerequisites & Dependencies

To run this project, you need two machines:

### 1. The Host PC (Laptop/Desktop)
*OS: Windows, Mac, or Linux*
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (must be running)
- [Node.js](https://nodejs.org/) (v18+)
- Git

### 2. The Robot Edge (Jetson Orin Nano)
*OS: Ubuntu 22.04*
- Intel RealSense D435i Camera (Must be plugged into a **BLUE USB 3.0 port**)
- Internet connection (Must be on the **exact same Wi-Fi network** as the Host PC)

## 🚀 "Magic" Installation Guide

We have fully automated the setup process. You do not need to manually configure databases or ROS packages.

### Step 1: Setup the Host PC
1. Clone the repository on your laptop:
   ```bash
   git clone https://github.com/ashwinprabhu2005-del/mapping-robot-dashboard.git
   cd mapping-robot-dashboard
   ```
2. Run the automated PC setup script:
   ```bash
   ./magic_setup_pc.sh
   ```
   *This automatically provisions all Docker databases, installs frontend dependencies, and opens the Dashboard.*
3. **IMPORTANT:** At the end of the script, it will print your PC's IP address. Write it down.

### Step 2: Setup the Jetson Orin Nano
1. Clone the repository on the Jetson:
   ```bash
   git clone https://github.com/ashwinprabhu2005-del/mapping-robot-dashboard.git
   cd mapping-robot-dashboard
   ```
2. Run the automated Jetson setup script:
   ```bash
   ./magic_setup_jetson.sh
   ```
3. When prompted, enter the **PC's IP address** you wrote down earlier.
   *This script downloads ROS2, RealSense SDKs, sets up USB permissions, installs the Node backend, and configures an auto-start systemd service.*
4. **IMPORTANT:** At the end of the script, it will print the Jetson's IP address. Write it down.
5. Reboot the Jetson: `sudo reboot`

## 🎮 How to Use It Daily

Once installed, starting the system takes seconds.

1. **Start the PC Dashboard:**
   Run `./magic_setup_pc.sh` on your laptop. Open `http://localhost:5173` in your browser.
2. **Turn on the Jetson:**
   Plug the Jetson in. The Lifecycle Server starts automatically in the background.
3. **Launch the Camera:**
   - On the PC Dashboard Login Screen, enter the **Jetson's IP Address** as the User ID.
   - Enter **`admin`** as the Password.
   - Click **LOGIN & LAUNCH**.
   - *The dashboard will remotely command the Jetson to fire up the depth camera, and the 3D map will begin streaming!*
4. **Shut Down:**
   Click **LOGOUT** in the top right of the dashboard, or simply close the browser tab. The Jetson will detect the closed connection and safely shut down the camera.

## 🚑 Troubleshooting

- **"Cannot reach Jetson launch server":** Ensure both the PC and Jetson are on the exact same Wi-Fi network.
- **"No Camera Data":** Ensure the RealSense camera is in a blue USB 3.0 port. Black ports will cause silent failures.
- **"IP Address Changed":** If your router reassigns IP addresses, open `amr_data_publisher/config/publisher_config.yaml` on the Jetson and update the `docker_host_ip` manually.
